# 标题配置快速参考

## 🚀 快速开始

### 立即使用（无需修改）
当前配置已可正常使用，标题显示为："页面标题 | My Personal Blog"

### 快速修改选项

#### 选项1：极简模式
```yaml
title: ""
```
效果：只显示页面标题（需要额外处理SEO插件兼容性）

#### 选项2：简洁模式
```yaml
title: Blog
```
效果：页面标题 | Blog

#### 选项3：自定义模式
```yaml
title: 我的技术笔记
```
效果：页面标题 | 我的技术笔记

## 🔧 修改步骤

1. 打开 `_config.yml` 文件
2. 找到 `title:` 行
3. 修改为想要的标题
4. 保存文件
5. 重新构建：`bundle exec jekyll build`
6. 启动测试：`bundle exec jekyll serve`

## 📋 常用标题模板

| 类型 | 配置示例 | 适用场景 |
|------|----------|----------|
| 个人博客 | `title: 张三的博客` | 个人品牌建设 |
| 技术分享 | `title: Tech Share` | 技术内容为主 |
| 知识整理 | `title: Knowledge Hub` | 知识库类型 |
| 日记随笔 | `title: Daily Notes` | 个人记录 |

## ⚠️ 注意事项

- 标题不能为空字符串（会引起构建错误）
- 建议使用2-5个词的简洁标题
- 修改后需要重新构建才能看到效果
- 本地测试地址：http://localhost:4000

## 🎯 推荐配置

对于大多数用户，推荐使用：
```yaml
title: My Blog  # 简洁明了，易于记忆
```
