| 概念     | 含义                                   |
| -------- | -------------------------------------- |
| 不补     | 当前亏损多少，就需要更高涨幅才能回本   |
| 补 1 倍  | 再投入和原持仓差不多的钱，摊低成本     |
| 补 2 倍  | 再投入约 2 倍资金，进一步摊低成本      |
| 回本涨幅 | 从补仓后的成本位置，涨多少才能回到本金 |

注意：这张表只是在说明**补仓会降低账面亏损比例和回本涨幅**，不代表一定应该补仓。补仓前还要看基金质量、仓位、现金流和市场趋势。

亏 10% 补 1 倍 里的 **补 1 倍**，一般指：

举例：

你原来买了：

```
本金：10000 元
当前亏 10%
当前市值：9000 元
```

如果“补 1 倍”按原始本金算，就是再买：

```
补仓：10000 元
```

补完后：

```
总投入本金：20000 元
当前总市值：9000 + 10000 = 19000 元
```

此时亏损：

```
亏损金额 = 20000 - 19000 = 1000 元
亏损比例 = 1000 / 20000 = 5%
```

所以表里写：

```
亏 10%，补 1 倍 -> 补后亏 -5%，回本涨 +5.3%
```

回本为什么是 `+5.3%`？

因为现在市值是 `19000`，要涨回 `20000`：

```
1000 / 19000 = 5.26%
```

约等于：

```
+5.3%
```
