```go
func getSendChannel(action *model.ActionInfo) sendChannel {
	if action == nil || action.ExtraData == nil {
		return sendChannelMqtt
	}
	if channelVal, ok := action.ExtraData["channel"]; ok {
		ch := sendChannel(channelVal)
		switch ch {
		case sendChannelPulsar, sendChannelMqtt:
			return ch
		}
	}
	return sendChannelMqtt
}
```

### 

| 场景                                 | 结果   | 说明                        |
| ------------------------------------ | ------ | --------------------------- |
| `action == nil`                      | ✅ 安全 | 第一个 if 会返回            |
| `action.ExtraData == nil`            | ✅ 安全 | map 读取返回 `(nil, false)` |
| `action.ExtraData == {}`             | ✅ 安全 | ok 为 false，返回默认值     |
| `action.ExtraData["channel"]` 不存在 | ✅ 安全 | ok 为 false，返回默认值     |

**结论：代码是安全的，但建议显式检查 `action.ExtraData == nil` 以提高代码可维护性。**
