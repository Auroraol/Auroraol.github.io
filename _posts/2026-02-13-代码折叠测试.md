### 长代码块（应该显示折叠按钮）

```python
def fibonacci(n):
    """计算斐波那契数列"""
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)

def main():
    # 计算前20个斐波那契数
    for i in range(20):
        print(f"F({i}) = {fibonacci(i)}")
    
    # 一些额外的代码行来测试折叠功能
    print("这是第1行")
```

```go
package main

import (
```
