目标：把
**16 Core | 32 GiB | 20 GiB 系统盘**
缩到 **CPU、内存、磁盘「 120 min 平均 ≤ 50 %」**，并留 20 % 突发缓冲。

------

### 1. 图中「 120 min 平均」峰值（11-14 20:00）

表格

复制

| 指标       | 峰值              | 占当前总量百分比 |
| :--------- | :---------------- | :--------------- |
| CPU        | 0.102 %           | 0.102 %          |
| 内存       | 1.000 % ≈ 320 MiB | 1 %              |
| 磁盘使用率 | 0.7 % ≈ 140 MiB   | 0.7 %            |

------

### 2. 反推「 ≤ 50 % 使用率」所需资源

表格

复制

| 资源 | 峰值用量   | 目标利用率 ≤ 50 %        | 理论最小值 | 留 20 % 缓冲            | 建议规格                       |
| :--- | :--------- | :----------------------- | :--------- | :---------------------- | :----------------------------- |
| CPU  | 0.016 Core | 0.016 / 0.5 = 0.032 Core | 0.032 Core | 0.032 / 0.8 ≈ 0.04 Core | **0.5 Core**（云厂商最小粒度） |
| 内存 | 0.32 GiB   | 0.32 / 0.5 = 0.64 GiB    | 0.64 GiB   | 0.64 / 0.8 ≈ 0.8 GiB    | **1 GiB**（再小就 2 GiB）      |
| 磁盘 | 0.14 GiB   | 0.14 / 0.5 = 0.28 GiB    | 0.28 GiB   | 0.28 / 0.8 ≈ 0.35 GiB   | **20 GiB**（已最低，无法再降） |

------

### 3. 最终建议

表格

复制

| 维度 | 建议值       | 说明                  |
| :--- | :----------- | :-------------------- |
| CPU  | **0.5 Core** | 富余 12 倍，仍 < 50 % |
| 内存 | **2 GiB**    | 富余 6 倍，可再压到   |
