## 命令

### **如果你想编辑 Deployment**（修改 Pod 模板、副本数等）：

```bash
kubectl -n dev-lane edit deployment chatbot-client-deploy
```

### **如果你想编辑 Service**（修改端口映射、类型等）：

```bash
kubectl -n dev-lane edit svc chatbot-client-service
```

#### **端口配置** (`spec.ports`)

```yaml
ports:
  - name: http
    port: 8080          # 服务内部端口
    targetPort: 8080    # 转发到 Pod 的哪个端口
    nodePort: 32198     # NodePort 类型时，宿主机映射端口 (30000-32767)
    protocol: TCP
```

#### **服务类型** (`spec.type`)

- `ClusterIP` - 仅集群内部访问（默认）
- `NodePort` - 通过节点 IP + 端口访问
- `LoadBalancer` - 云厂商负载均衡
- `ExternalName` - 映射外部域名

#### **选择器** (`spec.selector`)

```yaml
selector:
  app: chatbot-client   # 匹配哪些 Pod 的标签
```

### **先确认 deployment 的实际名称**：

```bash
kubectl -n dev-lane get deployment | grep chatbot
```
