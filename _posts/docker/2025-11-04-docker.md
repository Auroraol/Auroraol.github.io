镜像

```bash
# 登录docker
docker login -u 账号 -p 密码 registry.cn-zhangjiakou.aliyuncs.com
# 拉取镜像
docker pull registry.cn-xxxxx.aliyuncs.com/xxxxx/ecrobot-xxx-dy:v0.1.37
# tag
docker tag ad2a5ed8bc4c  opcloud-micro-2101562073-cn-beijing.cr.volces.com/custom_ns_9671760171634316/sdk-xxx:feature-micro_app
# 推送镜像
docker push opcloud-micro-2101562073-cn-beijing.cr.volces.com/custom_ns_9671760171634316/sdk-xxx:feature-micro_app
```

docker测试

```
删除镜像 ID：
docker rmi 3df247021efd
# 停旧容器
docker rm -f ecrobot-sdk-xxx

# 确保宿主机存在这个文件：/opt/sdk-dy/sdk-dy.toml
# 镜像运行, 按 Dockerfile 的默认 Cmd 运行（会读取 -c /etc/config/sdk-xxx.toml）
docker run -d --name ecrobot-xxx-dy \
  -p 8091:8091 -p 8093:8093 \
  -v /opt/sdk-dy/sdk-dy.toml:/etc/config/sdk-xxx.toml:ro \
  registry.cn-xxxx.aliyuncs.com/xxxx/ecrobot-sdk-xxx:feat-micro_app
```
