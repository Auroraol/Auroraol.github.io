## 框架

**二叉树的所有递归解法，本质上都是前/中/后序遍历的变体**。

```go
func traverse(root *TreeNode){
    // 前序位置：刚进入节点时
    traverse(root.Left)
    // 中序位置：左子树处理完，右子树之前
    traverse(root.Right)
    // 后序位置：左右子树都处理完，即将离开节点时
}
```

**框架的通用套路**

```
1. 拿到题目，想：需要在什么时候做计算？
   - 刚看到节点时？→ 前序位置
   - 处理完左子树后？→ 中序位置  
   - 处理完左右子树后？→ 后序位置 

2. 递归函数返回什么？（给父节点用的信息）
3. 额外维护什么全局/外部变量？
```

## 以 LeetCode 124 为例

```go
func maxPathSum(root *TreeNode) int {
    ans := math.MinInt32
    
    // 匿名函数
    var dfs func(root *TreeNode) int
    dfs = func(root *TreeNode) int {
        if root == nil { return 0 }
        
        // 1. 递归处理左子树（相当于 traverse(root.Left)）
        left := max(0, dfs(root.Left))
        
        // 2. 递归处理右子树（相当于 traverse(root.Right)）
        right := max(0, dfs(root.Right))
        
        // 3. ⭐ 后序位置：左右子树结果都有了，计算当前节点的路径和
        //    这就是 "后序遍历" 的位置！
        ans = max(ans, left + right + root.Val)
        
        // 4. 返回给父节点用的值（只能选一边，因为路径不能分叉）
        return max(max(left, right) + root.Val, 0)
    }
    
    dfs(root)
    return ans
}

func max(x, y int) int{
    if x > y{
        return x
    }
    return y
}
```

```
1. 拿到题目，想：需要在什么时候做计算？
   - 刚看到节点时？→ 前序位置
   - 处理完左子树后？→ 中序位置  
   - 处理完左右子树后？→ 后序位置 ← 本题

2. 递归函数返回什么？（给父节点用的信息）
   - 本题：返回单条最大路径（只能选左或右，不能分叉）

3. 额外维护什么全局/外部变量？
   - 本题：ans 记录全局最大路径和（可能跨左右子树）
```



## **LeetCode 104 求最大深度**

```go
func maxDepth(root *TreeNode) int {
    if root == nil { return 0 }
    
    // 但本题其实用后序更自然：
    leftDepth := maxDepth(root.Left)   // 遍历左
    rightDepth := maxDepth(root.Right) // 遍历右
    
    // 后序位置：左右深度都知道了，取最大+1
    return max(leftDepth, rightDepth) + 1
}
```

## LeetCode 105 题

```go
func buildTree(preorder []int, inorder []int) *TreeNode {
    if len(preorder)==0 || len(inorder)==0{
        return nil
    }
    // 前序遍历
    root := &TreeNode{preorder[0],nil,nil} // root 是指针型
    i := 0
    for ; i < len(inorder); i++{
        if inorder[i] == preorder[0]{
            break
        }  
    }
    //
    root.Left = buildTree(preorder[1:len(inorder[:i])+1], inorder[:i])
    root.Right = buildTree(preorder[len(inorder[:i])+1:], inorder[i+1:])
    return root
}
```







不要看这个函数的参数很多，只是为了控制数组索引而已。注意找递归函数的位置，本质上该算法也就是一个前序遍历，因为它在前序遍历的位置加了一坨代码。

LeetCode 99 题，难度 Hard，恢复一棵 BST二叉搜索树，主要代码如下【递归、隐式中序遍历，难】：

```go
var x, y, parent *TreeNode

func recoverTree3(root *TreeNode) {
	x, y, parent = nil, nil, nil
	traverse(root)
	x.Val, y.Val = y.Val, x.Val
}
func traverse(root *TreeNode) {
	if root == nil {
		return
	}
	traverse(root.Left)
	// 中序遍历
	if parent != nil && parent.Val > root.Val {
		y = root
		if x == nil {
			x = parent
		} else {
			return
		}
```

这不就是个中序遍历嘛，对于一棵 BST 中序遍历意味着什么，应该不需要解释了吧。

你看，Hard 难度的题目不过如此，而且还这么有规律可循，只要把框架写出来，然后往相应的位置加东西就行了，这不就是思路吗。

对于一个理解二叉树的人来说，刷一道二叉树的题目花不了多长时间。那么如果你对刷题无从下手或者有畏惧心理，不妨从二叉树下手，前 10 道也许有点难受；结合框架再做 20 道，也许你就有点自己的理解了；刷完整个专题，再去做什么回溯动规分治专题，**你就会发现只要涉及递归的问题，都是树的问题**。









# 二叉树解题完全手册（终极模板版）

## 一、核心认知：二叉树 = 递归

**所有二叉树问题，本质都是：**

> **在当前节点做什么选择？ + 递归处理子树 + 整合结果**

------

## 二、通用递归框架（万能模板）

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

// 万能递归框架
func traverse(root *TreeNode) {
    // 1. 基准情况（必须）
    if root == nil {
        return
    }
    
    // 2. 前序位置：刚进入节点（自顶向下传递信息）
    // 此时：只知道当前节点，子树还没处理
    // 用途：打印、路径记录、参数传递、剪枝判断
    
    traverse(root.Left)   // 递归左子树
    
    // 3. 中序位置：左子树处理完，右子树之前（BST专用）
    // 此时：左子树全部处理完毕，可以利用左子树的结果
    // 用途：BST验证、第K小元素、有序性相关
    
    traverse(root.Right)  // 递归右子树
    
    // 4. 后序位置：左右子树都处理完（自底向上汇总信息）
    // 此时：左右子树的结果都有了，可以整合计算
    // 用途：求深度、直径、路径和、子树性质判断（如平衡二叉树）
}
```

## 三、六大题型模板

### 题型 1：遍历搜索型（前序位置为主）

**特征**：只需要访问每个节点，不需要子树返回信息
**模板**：

go

复制

```go
func search(root *TreeNode, target int) bool {
    if root == nil {
        return false
    }
    
    // 前序位置：检查当前节点
    if root.Val == target {
        return true
    }
    
    // 递归搜索左右（或只搜一边）
    return search(root.Left, target) || search(root.Right, target)
}
```

**例题**：寻找值为x的节点、统计节点个数、检查是否存在某值

### 题型 2：深度/高度型（后序位置）

**特征**：需要知道子树高度，返回当前树高度给父节点
**核心公式**：`height = max(leftHeight, rightHeight) + 1`

go

复制

```go
// 基础版：求最大深度
func maxDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }
    leftDepth := maxDepth(root.Left)    // 左子树深度
    rightDepth := maxDepth(root.Right)  // 右子树深度
    
    // 后序位置：整合左右结果
    return max(leftDepth, rightDepth) + 1
}

// 进阶版：判断平衡二叉树（需要后序位置判断）
func isBalanced(root *TreeNode) bool {
    var balanced bool = true
    
    var dfs func(*TreeNode) int
    dfs = func(root *TreeNode) int {
        if root == nil || !balanced {  // 剪枝：已不平衡直接返回
            return 0
        }
        
        left := dfs(root.Left)
        right := dfs(root.Right)
        
        // 后序位置：检查平衡条件
        if abs(left-right) > 1 {
            balanced = false
        }
        
        return max(left, right) + 1
    }
    
    dfs(root)
    return balanced
}
```

### 题型 3：路径型（后序位置 + 外部变量）

**特征**：存在"跨左右"的路径，但只能返回单边给父节点
**必须**：用外部变量记录全局最优

go

复制

```go
// 最大路径和模板
func maxPathSum(root *TreeNode) int {
    ans := math.MinInt32
    
    var dfs func(*TreeNode) int
    dfs = func(root *TreeNode) int {
        if root == nil {
            return 0
        }
        
        // 递归获取左右子树贡献（负数舍去，相当于剪枝）
        left := max(0, dfs(root.Left))
        right := max(0, dfs(root.Right))
        
        // 【后序位置】计算跨左右的路径（不能返回给父节点，用外部变量记录）
        ans = max(ans, left + right + root.Val)
        
        // 返回单边最大给父节点（父节点只能接一边）
        return max(left, right) + root.Val
    }
    
    dfs(root)
    return ans
}

// 直径模板（几乎一样）
func diameterOfBinaryTree(root *TreeNode) int {
    ans := 0
    
    var dfs func(*TreeNode) int
    dfs = func(root *TreeNode) int {
        if root == nil {
            return 0
        }
        
        left := dfs(root.Left)
        right := dfs(root.Right)
        
        // 后序位置：直径 = 左深度 + 右深度
        ans = max(ans, left + right)
        
        // 返回深度给父节点
        return max(left, right) + 1
    }
    
    dfs(root)
    return ans
}
```

### 题型 4：构建型（前序位置 + 分解问题）

**特征**：根据遍历序列构建树，先确定根，再递归构建子树

go

复制

```go
// 前序+中序构建
func buildTree(preorder []int, inorder []int) *TreeNode {
    if len(preorder) == 0 {
        return nil
    }
    
    // 前序位置：第一个元素是根
    root := &TreeNode{Val: preorder[0]}
    
    // 在中序中找到根的位置
    var rootIndex int
    for i, v := range inorder {
        if v == preorder[0] {
            rootIndex = i
            break
        }
    }
    
    leftSize := rootIndex // 左子树节点数
    
    // 递归构建（注意切分范围）
    root.Left = buildTree(preorder[1:1+leftSize], inorder[:rootIndex])
    root.Right = buildTree(preorder[1+leftSize:], inorder[rootIndex+1:])
    
    return root
}
```

### 题型 5：BST专用（中序位置）

**特征**：利用BST"左<根<右"的有序性，中序遍历即为升序

go

复制

```go
// 验证BST（中序位置检查）
func isValidBST(root *TreeNode) bool {
    var prev *TreeNode  // 记录中序前一个节点
    
    var dfs func(*TreeNode) bool
    dfs = func(root *TreeNode) bool {
        if root == nil {
            return true
        }
        
        if !dfs(root.Left) {
            return false
        }
        
        // 【中序位置】检查有序性
        if prev != nil && prev.Val >= root.Val {
            return false
        }
        prev = root
        
        return dfs(root.Right)
    }
    
    return dfs(root)
}

// 第K小元素（中序计数）
func kthSmallest(root *TreeNode, k int) int {
    var ans int
    var count int
    
    var dfs func(*TreeNode)
    dfs = func(root *TreeNode) {
        if root == nil {
            return
        }
        
        dfs(root.Left)
        
        // 中序位置：计数
        count++
        if count == k {
            ans = root.Val
            return
        }
        
        dfs(root.Right)
    }
    
    dfs(root)
    return ans
}
```

### 题型 6：最近公共祖先（LCA）

**特征**：后序位置，利用返回值传递信息（找到目标返回目标，否则返回nil）

go

复制

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    if root == nil || root == p || root == q {
        return root
    }
    
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)
    
    // 后序位置分析结果
    if left != nil && right != nil {
        return root  // 左右各找到一个，当前就是LCA
    }
    if left != nil {
        return left  // 只在左边找到
    }
    return right     // 只在右边找到或都没找到
}
```

## 四、设计递归的决策树

plain

复制

```plain
开始
  │
  ├─ 需要子树返回信息？（后序）
  │   ├─ 是 → 需要"跨左右"计算？（路径和/直径）
  │   │       ├─ 是 → 返回值（单边）+ 外部变量（全局）
  │   │       └─ 否 → 返回值（整合后）
  │   └─ 否 → 进入下一步
  │
  ├─ 需要利用有序性？（BST）
  │   └─ 是 → 中序位置处理
  │
  ├─ 需要先确定根？（构建）
  │   └─ 是 → 前序位置处理
  │
  └─ 只需遍历？（搜索/打印）
      └─ 前序位置处理
```

## 六、避坑指南

表格





| 坑             | 说明                                                     | 解决                                                         |
| :------------- | :------------------------------------------------------- | :----------------------------------------------------------- |
| **只接单边**   | 路径型题目，父节点只能接左或右，不能同时接               | 返回`max(left, right) + root.Val`，不要用`left+right+root.Val` |
| **负数剪枝**   | 路径和可能为负时，要`max(0, dfs(...))`舍弃负贡献         | 否则负数会让总和变小                                         |
| **返回值类型** | 有时需要返回`bool`（是否找到），有时返回`int`（深度/和） | 根据题意设计，必要时用闭包/全局变量补充                      |
| **BST中序**    | 验证BST时，注意是`>`和`<`，不是`>=` `<=`                 | 用`prev`指针记录前一个节点比较                               |
