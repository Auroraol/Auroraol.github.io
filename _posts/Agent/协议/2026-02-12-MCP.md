# LangChain-MCP

> **<font style="color:#DF2A3F;">大模型和外部工具交互的标准化协议</font>**

模型上下文协议(MCP ModelContextProtocol)正迅速成为AI领域的核心基础设施标准，它通过标准化大语言模型与外部工具的交互方式，解决了AI应用开发中的关键瓶颈，推动了智能体从实验室走向商业化的进程

# <font style="color:rgb(44, 44, 54);">MCP的原理</font>

MCP的核心原理：

![image-20260214153312204](https://github.com/Auroraol/Drawing-bed/raw/main/img/image-20260214153312204.png)

与上一张图异曲同工：

![image-20260214153322435](https://github.com/Auroraol/Drawing-bed/raw/main/img/image-20260214153322435.png)

MCP 的核心原理是将互联网服务（高德、谷歌）或本地操作系统 API（文件系统、数据库、终端）封装成 **<u><font style="color:#DF2A3F;">AI 智能体能够理解和使用的 Tools 工具</font></u>**，让 AI 智能体能够自由地调用这些 Tools 工具实现复杂的业务逻辑和功能。
