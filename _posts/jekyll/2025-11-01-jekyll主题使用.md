# 本地部署环境和调试

不同的操作系统可能会不太一样，这里以Windows举例，配置本地调试环境：

1. 安装RUBY

   访问 [Ruby Installer](https://rubyinstaller.org/downloads/) 下载

   记得下载带devkit的版本

   安装过程中，如果有类似MSYS2 and MINGW development tool chain的选项，记得勾选

   安装成功后，使用命令行验证安装结果：` ruby -v gem -v `

2. 安装Jekyll

   ` gem install jekyll bundler `

   安装成功后，使用命令行验证安装结果：` jekyll -v `

   更换国内镜像

   ```
   1.修改gem的source ：
   gem sources --remove https://rubygems.org/
   2.改为可以使用的：
   gem sources -a 'https://gems.ruby-china.com'
   3.查看当前有的source
    gem sources -l
   ```

3. 运行项目

   首先使用git clone拉到项目所有文件，然后进入项目根目录文件夹中

   运行命令：` bundle config mirror.https://rubygems.org https://gems.ruby-china.com `

   使用命令

   ` bundle exec jekyll serve ` 进入 http://127.0.0.1:4000/

之所以需要在本地预览调试，是因为GitHub对打包次数有要求，目前规定是每小时10次打包次数（2024年1月4日），建议做一些细微调整的时候，不要用线上环境进行调试工作。
